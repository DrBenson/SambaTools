* SambaTools v0.1

  The SambaTools is a toolset for Smaba server setting tools.
It can add users, groups to Samba server. and setup users quota for share folders. Also create users, groups account to Linux system.

* Feture:
- Add user accound and group to Linux in the same time, also create same account for Samba user.
- Change user group also move Samba user share folder to new group folder.
- Change user password.
- Modify user quota size.
- Show Samba server status.
and much more.....
